# Changelog

## v1.1.0

Feature update for **earStep**.

- Per-sample output routing: MAIN / OUT 2 ... OUT 16
- Auto Output Routing with sequential track assignment and Reset Routing
- WAV export for Current Pattern and Song
  - Mix
  - Individual Sounds
- Active samples move to the top of the list and show their ring/track number
- Clicking an active sample in the list selects its track
- MIDI Thru and expanded playback settings
- Settings and Export panels close when clicking outside
- Swing label alignment improvements
- Safer multi-output handling after testing
- Removed redundant Output Stems export option
- Removed experimental double-click ring selection

## v1.0.0

First public release of **earStep**.

- macOS: VST3 / AU / Standalone
- Windows x64: VST3 / Standalone
- Linux x86_64: VST3 / Standalone
- Circular step-sequencer workflow
- Sample-based sequencing
- Host tempo sync, Swing and Grid controls
- Per-step velocity, probability and ratchet controls
- Multiple UI themes
